[Beat This! issue #13](https://github.com/CPJKU/beat_this/issues/13), by Paulllux, is a useful **idea-only** tempo candidate. Its scripts trim edge beats, reject interval outliers, estimate grid phase with a circular mean, and regress beat timestamps against rounded grid indices. This can reduce local interval jitter when tempo is stable. A separate octave correction folds tempo into 78–185 BPM; that range is a preference, not a general solution to tempo ambiguity. Keep it optional. The author reports GiantSteps results, but the heuristic was tuned on that dataset and held-out evidence is absent. Test missing/duplicate beats, outliers, short inputs, silence, tempo drift, and compound meter. Six inspected attachments have SHA-256 hashes in the catalogue; they have no explicit script licence. The CoreML scripts target Beat This models, not madmom weights. [Madmom #416](https://github.com/CPJKU/madmom/issues/416) is earlier linear-regression tempo provenance.
